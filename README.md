# Superstore Sales Performance Dashboard

## Project Overview
This project focuses on analyzing Superstore sales data using Microsoft Excel to understand sales performance, customer trends, and product category performance.

## Key Features
- Total Sales, Orders, and Customer KPIs
- Sales Analysis by Category and Sub-Category
- Regional Sales Performance
- Monthly and Yearly Sales Trends
- Interactive Dashboard and Pivot Tables

## Tools & Technologies
- Microsoft Excel
- Pivot Tables
- Excel Charts
- Data Analysis & Visualization

## Objective
To analyze sales data, identify business trends, and present meaningful insights through an interactive Excel dashboard.
